# Portfolio — Thân Ngọc Huyên

Next.js 16 portfolio starter for Graphic Designer & Video Editor. Deploy on Vercel (Node.js 24+).

## Local

```bash
npm install
npm run dev
```

## Important

This GitHub version contains a working portfolio UI and placeholder project artwork. The seven original videos are **not yet uploaded**: they remain in the downloadable complete ZIP from ChatGPT. Replace placeholder email `hello@example.com` before publishing. The original video files can be added to the site using a suitable external media host or uploaded through Git LFS.
